# Full-Body Beginner Program (3-Day)

## Overview
A linear-progression, full-body program for lifters in their first 0-6 months of training.
Trained on non-consecutive days (e.g., Mon/Wed/Fri), alternating Workout A and Workout B.

## Workout A
- Goblet Squat (or Barbell Squat if available) — 3 sets x 8-10 reps, rest 2 min
- Dumbbell Bench Press (or push-up if no bench) — 3 sets x 8-10 reps, rest 2 min
- Single-Arm Dumbbell Row — 3 sets x 10 reps/side, rest 90 sec
- Plank — 3 sets x 30-45 sec hold
- Dumbbell Shoulder Press — 2 sets x 10-12 reps, rest 90 sec

## Workout B
- Romanian Deadlift (dumbbell or barbell) — 3 sets x 8-10 reps, rest 2 min
- Incline Push-Up (or Dumbbell Incline Press) — 3 sets x 10-12 reps, rest 90 sec
- Lat Pulldown (or resistance band row if no machine) — 3 sets x 10-12 reps, rest 90 sec
- Dumbbell Lunge — 2 sets x 10 reps/leg, rest 90 sec
- Dead Bug — 3 sets x 10 reps/side

## Equipment Note
Designed to work with a minimal home-gym setup: an adjustable dumbbell set and, ideally, a
bench. No barbell or squat rack required, though substitutions are provided for a fuller
commercial gym.

## Progression Rule
Increase load (or reps, if using bodyweight variations) any session where all sets hit the top
of the rep range with two reps left in reserve. If a lift stalls for 2 sessions, drop weight by
10% and rebuild.

## Notes
Best for someone training 3x/week with 30-45 minutes per session and little to no prior
resistance-training experience.
