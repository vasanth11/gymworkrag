# Upper / Lower Split (4-Day)

## Overview
Trains upper and lower body twice each per week (Upper A, Lower A, Upper B, Lower B), balancing
strength work early in each session with hypertrophy accessories after. Good middle ground
between a full-body beginner routine and a 6-day PPL split.

## Day 1: Upper A
- Barbell Bench Press — 4 sets x 5 reps, rest 2-3 min
- Barbell Row — 4 sets x 6-8 reps, rest 2 min
- Seated Dumbbell Shoulder Press — 3 sets x 8-10 reps, rest 90 sec
- Lat Pulldown — 3 sets x 10-12 reps, rest 90 sec
- Dumbbell Curl — 2 sets x 10-12 reps, rest 60 sec
- Triceps Pushdown — 2 sets x 10-12 reps, rest 60 sec

## Day 2: Lower A
- Back Squat — 4 sets x 5 reps, rest 2-3 min
- Romanian Deadlift — 3 sets x 8 reps, rest 2 min
- Leg Press — 3 sets x 10-12 reps, rest 90 sec
- Seated Leg Curl — 3 sets x 10-12 reps, rest 60 sec
- Standing Calf Raise — 3 sets x 12-15 reps, rest 45 sec

## Day 3: Upper B
- Overhead Press — 4 sets x 6-8 reps, rest 2 min
- Pull-Up — 3 sets x max reps (add weight if >12), rest 2 min
- Incline Dumbbell Press — 3 sets x 8-10 reps, rest 90 sec
- Seated Cable Row — 3 sets x 10-12 reps, rest 90 sec
- Face Pull — 2 sets x 15-20 reps, rest 60 sec
- Hammer Curl — 2 sets x 10-12 reps, rest 60 sec

## Day 4: Lower B
- Deadlift — 3 sets x 5 reps, rest 3 min
- Front Squat — 3 sets x 6-8 reps, rest 2 min
- Walking Lunge — 3 sets x 10 reps/leg, rest 90 sec
- Leg Extension — 3 sets x 12-15 reps, rest 60 sec
- Seated Calf Raise — 3 sets x 15 reps, rest 45 sec

## Progression Rule
Add weight to the day's first compound lift every session it's completed for all sets/reps;
if a set is missed, hold the weight and retry next week before advancing.

## Notes
Requires a full gym setup (barbell, rack, dumbbells, cable machine, leg press). Good for
lifters with 3-4 days/week available and roughly 60-75 minutes per session.
