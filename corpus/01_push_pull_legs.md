# Push / Pull / Legs (6-Day)

## Overview
A 6-day hypertrophy-focused split that trains each muscle group twice per week by rotating
through Push, Pull, and Legs days twice in a 7-day cycle (e.g., Push/Pull/Legs/Push/Pull/Legs/Rest).
Best suited for lifters with at least 6 months of consistent training who can recover from
high weekly volume.

## Day 1: Push (Chest, Shoulders, Triceps)
- Barbell Bench Press — 4 sets x 6-8 reps, rest 2-3 min
- Incline Dumbbell Press — 3 sets x 8-10 reps, rest 90 sec
- Seated Dumbbell Shoulder Press — 3 sets x 8-10 reps, rest 90 sec
- Cable Lateral Raise — 3 sets x 12-15 reps, rest 60 sec
- Triceps Rope Pushdown — 3 sets x 10-12 reps, rest 60 sec
- Overhead Cable Triceps Extension — 2 sets x 12-15 reps, rest 60 sec

## Day 2: Pull (Back, Biceps)
- Deadlift — 3 sets x 5 reps, rest 3 min
- Pull-Up (weighted if possible) — 4 sets x 6-10 reps, rest 2 min
- Barbell Row — 3 sets x 8-10 reps, rest 90 sec
- Seated Cable Row — 3 sets x 10-12 reps, rest 90 sec
- Face Pull — 3 sets x 15-20 reps, rest 60 sec
- Barbell Curl — 3 sets x 10-12 reps, rest 60 sec

## Day 3: Legs (Quads, Hamstrings, Glutes, Calves)
- Back Squat — 4 sets x 6-8 reps, rest 2-3 min
- Romanian Deadlift — 3 sets x 8-10 reps, rest 2 min
- Leg Press — 3 sets x 10-12 reps, rest 90 sec
- Walking Lunge — 3 sets x 12 reps/leg, rest 90 sec
- Leg Curl — 3 sets x 10-12 reps, rest 60 sec
- Standing Calf Raise — 4 sets x 12-15 reps, rest 45 sec

## Progression Rule
Add 2.5-5 lb to the main compound lift each week as long as all prescribed reps are completed
with good form. If a rep target is missed two sessions in a row, repeat the same weight next
session instead of adding load.

## Notes
Requires a full commercial gym (barbells, dumbbells, cable stack, leg press). Not suitable for
home-gym-only equipment.
